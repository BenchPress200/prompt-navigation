🚀 프롬프트 이동 버튼

ChatGPT 채팅창에서 도구 버튼 근처에 표시되는 네비게이션 버튼들입니다.

⬆︎

이전 질문으로 이동

Ctrl + Shift + ↑ (Windows)

Cmd + Shift + ↑ (Mac)

⬇︎

다음 질문으로 이동

Ctrl + Shift + ↓ (Windows)

Cmd + Shift + ↓ (Mac)

📖

프롬프트 목록 보기

Ctrl + Shift + / (Windows)

Cmd + Shift + / (Mac)

🚀

확장 프로그램 창 열기

Ctrl + Shift + ; (Windows)

Cmd + Shift + ; (Mac)

📝 자동 프롬프트 저장

🔍 정규식 검색

저장된 프롬프트를 정규식으로 빠르게 검색할 수 있습니다.

📍 현재 질문 표시

긴 답변을 읽을 때 우측 상단에 현재 질문이 표시됩니다.

📋 복사 및 이동

저장된 프롬프트를 클립보드에 복사하거나 해당 채팅으로 바로 이동할 수 있습니다.

⚙️ 사용 팁

💡

단축키를 사용하면 마우스 없이도 빠르게 이전/다음 질문으로 이동할 수 있습니다.

🔎

프롬프트 목록 모달에서 정규식을 사용해 특정 키워드가 포함된 질문을 빠르게 찾을 수 있습니다.
