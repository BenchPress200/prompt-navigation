## 개인정보처리방침

### 단일 용도
```
이 확장 프로그램은 ChatGPT 웹사이트에서 네비게이션 기능을 제공하고 사용자의 프롬프트를 로컬에 저장하는 단일 용도로만 사용됩니다.
```

### 저장 및 공개
```
사용자 데이터의 사용 및 전송에 대한 공개:

본 확장 프로그램은 다음과 같이 사용자 데이터를 처리합니다:

1. 데이터 수집
   - ChatGPT에서 입력한 질문 텍스트
   - 질문 입력 시간
   - 현재 채팅 세션 정보

2. 데이터 저장
   - 모든 데이터는 Chrome의 로컬 스토리지에만 저장됩니다
   - 외부 서버로 전송하지 않습니다
   - 다른 웹사이트나 서비스와 공유하지 않습니다

3. 데이터 사용 목적
   - 프롬프트 히스토리 표시
   - 질문 간 네비게이션 기능 제공
   - 검색 기능 제공

4. 데이터 삭제
   - 사용자는 언제든지 확장 프로그램의 "히스토리 삭제" 버튼으로 모든 저장된 데이터를 삭제할 수 있습니다
   - 확장 프로그램을 제거하면 모든 데이터가 자동으로 삭제됩니다

5. 제3자 공유
   - 사용자 데이터를 제3자와 공유하지 않습니다
   - 광고나 마케팅 목적으로 사용하지 않습니다
```

### 권한 사용 정당성

#### storage 권한
```
프롬프트 히스토리와 사용자 설정을 브라우저에 저장하기 위해 필요합니다. 모든 데이터는 로컬에만 저장되며 외부로 전송되지 않습니다.
```

#### activeTab 권한
```
현재 활성화된 ChatGPT 탭에서 네비게이션 버튼을 추가하고 사용자의 질문을 감지하기 위해 필요합니다. 다른 웹사이트에서는 작동하지 않습니다.
```

#### host_permissions (chatgpt.com, chat.openai.com)
```
ChatGPT 웹사이트에서만 확장 프로그램이 작동하도록 제한하기 위해 필요합니다. 지정된 도메인 외에는 접근하지 않습니다.
```
