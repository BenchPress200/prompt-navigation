
# chrome extension for chatgpt
## 구현해야 하는 기능
1. chatgpt.com 사이트의 채팅창 컴포넌트 중 "도구" 오른쪽에 "⬆︎", "⬇︎", "📖" 버튼 세개를 추가함. (버튼 모양은 예쁘게). 이 버튼 그룹을 "프롬프트 이동 버튼"이라고 명명함
   - 화살표 버튼을 누르면 현재 화면 기준으로 "사용자가 작성한 채팅"을 기준으로 스크롤 위치가 이동하게 만드는 것
     - 사이트에서 chatgpt의 답변 내용이 길어서 내가 작성한 채팅 내용을 가끔 까먹기 때문에 손쉽게 내용을 확인하기 위한 것
   - 편의성을 올리기 위해 macos 에서는 CMD+SHIFT+UP ARROW, CMD+SHIFT+DOWN ARROW 를 눌렀을 때 각각의 방향에 맞게 움직임
   - "📖"버튼을 누르면 현재 채팅을 기준으로 내가 입력한 프롬프트 목록을 모두 보여주는 모달이 나옴
     - ESC를 누르거나 모달 바깥을 누르면 손쉽게 꺼짐
     - 모달에 input area를 하나 추가해서 실행될 때 이 쪽으로 focusing 되도록 하여 편하게 사용할 수 있도록 함
       - 이 input area는 검색창이며 해당 채팅창에서 확인되는 채팅 내용을 정규식으로 필터링 되도록 할 것
       - 단축키로 진입할때, 버튼을 직접 눌러서 진입할 때 모두 input area에 focusing 되도록 할 것
     - 편의성을 올리기 위해 macos 에서는 CMD+SHIFT+SLASH(/) 를 눌렀을 때 모달창이 뜨도록 만들어.
   - 각각의 버튼에 마우스를 올리고 있으면 단축키가 표시되도록 만들어.
   - 단축키는 윈도우의 경우 맥의 "CMD"를 윈도우의 "CTRL"로 대응 되도록 만들어.
   - Chatgpt UI를 영어로 사용하는 사람들에게도 문제가 없도록 예외처리해.

2. 채팅 프롬프팅을 chrome extension 내에서 조회해볼 수 있음
   - 첨부파일 및 텍스트가 함께 보여야 함.
   - 해당 채팅 프롬프트 오른쪽에 복사 버튼과 해당 채팅 URL로 이동하는 버튼 두개를 추가함
     - 복사 버튼을 누르면 해당 채팅의 텍스트를 복사함
     - 이동 버튼을 누르면 해당 URL로 새 탭과 함께 이동함
   - chrome extension 상단에 탭 두개를 만들어서 "내가 입력한 프롬프트", "프롬프트 이동버튼 통해 확인된 프롬프트" 탭 두개를 만듦
     - "내가 입력한 프롬프트" 탭에서는 사용자가 프롬프트를 입력했을 때 해당 프롬프트의 모든 정보를 저장함
       - 예를 들어 첨부파일이 있는 경우 첨부파일도 저장해서 같이 chrome extension 에 보여야 함.
       - Chatgpt 채팅 내 기본 기능인 "도구"를 통해 무언가를 선택했다면 그 선택 값도 함께 저장함
         - 예를 들어 "도구"에는 "이미지 그리기", "웹에서 검색하기", "심층 리서치 실행"가 있는데 각각 "이미지", "웹", "심층"으로 저장해서 사용자 입장에서 내가 프롬프트를 실행할 때 어떤 옵션으로 실행했는지 직관적으로 알 수 있게 만들 것
     - 간혹 똑같은 프롬프트를 여러 탭에서 실행시키는 경우가 있음
       - 이 경우 유저가 입력한 프롬프트를 첫 줄에 표시해. 그리고 그 하위에 답변의 첫 줄 내용이 함께 표시되도록 만들고, 답변의 내용이 나오기 전에 종료 될 수도 있으니 답변을 기다리는 중에는 "대기중" 임을 표시하고 답변 얻기에 실패했다면 "실패" 임을 표시해.
   
3. chatgpt 사이트를 이용할 때 지금 보고 있는 답변의 질문내용이 무엇인지 화면에 직관적으로 표시 될 수 있도록 할 것.
    - 모달창 하단에 "다시 표시 하지 않기" 버튼을 추가하고 이 버튼을 누르면 모달창이 다시 표시하지 않도록 만들어 
    - chrome extension에 "설정" 탭을 하나 만들고 "현재 보는 답변의 질문을 우측 상단에 표시하기" 기능을 추가해. (ON/OFF는 토글 버튼으로 만들 것)

4. Chatgpt 채팅창에 진입하면 해당 화면에 있는 모든 사용자의 질문을 순서대로 수집 할 것. 예를 들어 "https://chatgpt.com/c/6846ed1e-b330-800c-adbf-96f551afbb73" 를 하나의 채팅으로 봄
   - 채팅 하나당 행 하나의 그룹을 만들고 이 그룹 하위에 내가 질문했던 프롬프팅과 해당 질문의 답변 첫 줄이 표시되도록 할 것.
   - 하나의 채팅에 해당하는 행을 클릭해서 목록을 접고 펼칠 수 있게 만들 것
   - 그룹 하위에 프롬프팅에 "이동"버튼을 눌렀을 때 해당 채팅의 프롬프트로 스크롤이 이동 되도록 만들 것.
     - 만약 해당 채팅이 현재 탭의 주소와 동일하면 새 탭을 띄우지 말고 해당 질문으로 이동 시킬 것
   - 하나의 그룹의 이름은 Chatgpt 에서 부여한 해당 채팅의 이름으로 표시되도록 만들 것
   - 유저가 질문을 추가하면 해당 질문과 답변도 추가 될 수 있도록 만들 것.

5. chrome extension 창에 input area를 하나 추가해서 정규식으로 채팅 검색 할 수 있도록 만들 것.
   - chrome extension 창이 띄워지는 순간 input area 로 focusing 되도록 할 것

6. chatgpt 홈페이지에서 CMD+SHIFT+SEMICOLON(;) 또는 CMD+SHIFT+E 를 누르면 chrome extension 창이 나오도록 할 것
   - 확장프로그램 창이 열리면 자동으로 검색 input area에 포커싱됨
